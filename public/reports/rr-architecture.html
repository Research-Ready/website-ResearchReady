## 2. Build Pipeline — BPMN Procesflow

Het platform kent twee deploypaden: **automatisch via GitHub Actions** (voor Quarto-content zonder ingebedde fonts) en **handmatig via Wrangler** (voor alles of wanneer de PublicPushGate hook de push blokkeert).

```{mermaid}
flowchart TD
  START(["Start\n(Auteur schrijft .qmd of .astro"]])

  START --> COMMIT["Auteur commit lokaal"]
  COMMIT --> PUSH_TRY["git push naar main"]

  PUSH_TRY --> GATE{PublicPushGate\nhook actief?}

  GATE -->|"Base64 fonts\ngedetecteerd"| BLOCKED["Push geblokkeerd\n(embed-resources: true)"]
  GATE -->|"Geen base64\n(embed-resources: false)"| GHA_TRIGGER["GitHub Actions\ngetriggerd op push"]

  BLOCKED --> LOCAL_FLOW["Lokale deploybaan"]

  subgraph LOCAL_FLOW["Lokale Deploy (handmatig)"]
    L1["quarto render quarto/presentations/"]
    L2["quarto render quarto/reports/"]
    L3["quarto render quarto/cert-prep/"]
    L4["npm run build"]
    L5["cp -r public/* dist/"]
    L6["wrangler pages deploy dist/\n--project-name research-ready"]
    L1 --> L2 --> L3 --> L4 --> L5 --> L6
  end

  subgraph GHA_FLOW["GitHub Actions (automatisch)"]
    G1["actions/checkout@v4"]
    G2["quarto-dev/quarto-actions/setup@v2"]
    G3["quarto render quarto/presentations/"]
    G4["quarto render quarto/reports/"]
    G5["quarto render quarto/cert-prep/"]
    G6["git add public/\ngit commit + push"]
    G1 --> G2 --> G3 --> G4 --> G5 --> G6
  end

  GHA_TRIGGER --> GHA_FLOW

  G6 --> CF_DEPLOY["Cloudflare Pages\nontvangen nieuwe bestanden"]
  L6 --> CF_DEPLOY

  CF_DEPLOY --> LIVE(["Site live op\nresearch-ready.nl"])
```

### 8.2 Change Management — Normal Change Proces

Elke inhoudelijke wijziging doorloopt het ITIL Normal Change proces. De git commit fungeert als **Request for Change (RFC)**.

```{mermaid}
flowchart TD
  RFC(["RFC: git commit\n(wijziging in .qmd of .astro)"])

  RFC --> CAT{"Change\nCategorie?"}

  CAT -->|"Content\n(.qmd tekst)"| STANDARD["Standard Change\n(lage impact, pre-approved)"]
  CAT -->|"Infrastructuur\n(workflow, wrangler, CF token)"| NORMAL["Normal Change\n(review vereist)"]

  STANDARD --> IMPACT_S["Impact Assessment:\nPublicPushGate scan\n(automatisch)"]
  NORMAL --> IMPACT_N["Impact Assessment:\nhandmatige review\n+ rollback-plan"]

  IMPACT_S --> GATE_S{Scan OK?}
  IMPACT_N --> APPROVE{Goedkeuring\nplatformbeheerder?}

  GATE_S -->|Ja| BUILD_S["Build:\nGHA of lokale render"]
  GATE_S -->|Nee — base64| REMEDIATE["Remediation:\nembed-resources: false\nof andere fix"]
  REMEDIATE --> RFC

  APPROVE -->|Ja| BUILD_N["Build:\nlokale render + npm build"]
  APPROVE -->|Nee| REJECT(["Change afgewezen\n→ backlog"])

  BUILD_S --> DEPLOY["Deploy:\nwrangler pages deploy dist/"]
  BUILD_N --> DEPLOY

  DEPLOY --> PIR["Post-Implementation Review:\nHTTP 200 verificatie\nop alle gewijzigde URLs"]

  PIR --> OK{Alle URLs\n200 OK?}
  OK -->|Ja| CLOSE(["Change gesloten\nCMDB bijgewerkt"])
  OK -->|Nee| INCIDENT["Incident geopend\n→ Incident Management §8.4"]
  INCIDENT --> ROLLBACK["Rollback:\nvorige Wrangler deploy\nopnieuw uitrollen"]
  ROLLBACK --> PIR
```

### 8.4 Incident Management

```{mermaid}
flowchart TD
  DETECT(["Incident gedetecteerd\n(404, build failure, deploy error)"])

  DETECT --> LOG["Incident gelogd\n(GitHub Issue aanmaken)"]
  LOG --> P{Prioriteit?}

  P -->|"P1 — site down"| P1["Directe actie:\nrollback vorige deploy\nvia Wrangler"]
  P -->|"P2 — pagina 404"| P2["Diagnose:\ncontroleer output-dir\nen URL-mapping"]
  P -->|"P3 — build fout"| P3["Diagnose:\nGHA logs lezen\nquarto render lokaal"]

  P1 --> RESTORE["Herstel:\nwrangler pages deploy\n(vorige dist/)"]
  P2 --> FIX_PATH["Fix:\ncorrectie in _quarto.yml\nof cp commando"]
  P3 --> FIX_BUILD["Fix:\nCSS key, engine, SCSS\n(zie §7 Beperkingen)"]

  RESTORE --> PIR2["PIR: root cause analyse\n→ kennisbank bijwerken"]
  FIX_PATH --> REDEPLOY["Opnieuw deployen"]
  FIX_BUILD --> REDEPLOY

  REDEPLOY --> VERIFY["Verificatie: HTTP 200"]
  VERIFY --> CLOSE2(["Incident gesloten"])
  PIR2 --> CLOSE2
```

### 8.5 Configuration Management Database (CMDB)

De GitHub-repository is het centrale **Configuration Management Database (CMDB)**. Elk bestand is een Configuration Item (CI).

| CI Type | Locatie | Verantwoordelijke | Wijzigingsprocedure |
|---|---|---|---|
| Astro broncode | `src/**` | Platform team | Normal Change via PR |
| Quarto content | `quarto/**` | Content team | Standard Change via commit |
| Build workflow | `.github/workflows/` | Platform team | Normal Change — handmatige review |
| Cloudflare API token | KeePass vault | Platformbeheerder | Rotatie elk kwartaal |
| Account ID / Project naam | KeePass vault | Platformbeheerder | Wijziging = infrastructuur change |
| Gegenereerde output | `public/**` | GHA / auteur | Automatisch — geen directe wijziging |
